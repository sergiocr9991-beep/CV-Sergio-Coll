# Sergio Coll Ramírez | Portafolio Web

Portafolio web personal de **Sergio Coll Ramírez**, Profesional en Diseño Gráfico.

Proyecto desarrollado como una landing page profesional para presentar perfil, experiencia, educación, habilidades y proyectos destacados de Behance.

## Vista del proyecto

El sitio está diseñado para funcionar como portafolio profesional en GitHub Pages.

## Contenido

- Perfil profesional
- Experiencia laboral
- Proyectos destacados
- Educación
- Herramientas
- Idiomas
- Enlaces a Behance, LinkedIn y YouTube
- Interacciones con scroll, filtros, modal de proyectos y copiado de contacto

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Diseño responsive
- Animaciones e interacciones nativas
- CSS embebido en un solo archivo

## Estructura

```txt
/
├── index.html
└── README.md
```

## Publicación en GitHub Pages

1. Subir `index.html` y `README.md` al repositorio.
2. Entrar a **Settings**.
3. Ir a **Pages**.
4. En **Build and deployment**, seleccionar:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guardar.

GitHub generará una URL pública del sitio.
